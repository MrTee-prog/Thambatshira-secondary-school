THAMBATSHIRA SECONDARY SCHOOL WEBSITE + INSTALLABLE WEB APP

GITHUB-READY FLAT FOLDER
All website files, images, icons and downloadable documents are in this same folder.
There are no assets/ or downloads/ subfolders.

MAIN FILES
- index.html: main school website
- style.css: responsive design and emblem watermark
- script.js: mobile navigation and admissions enquiry behaviour
- school-emblem.jpeg / school-emblem.png: school emblem files
- school-principal.jpeg: principal portrait
- icon-192.png / icon-512.png: PWA icons
- manifest.json / service-worker.js: installable PWA files
- parent-consent.html / privacy.html: supporting pages
- Thambatshira_Admission_Application.pdf: recreated admission form for printing
- Thambatshira_Admission_Application.html: browser-editable admission form
- parent-guardian-event-trip-consent-form.pdf and .docx: reusable consent form

PREVIEW
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server.

GITHUB PAGES
Upload/commit every file in this folder together into the root of the repository.
Do not upload only index.html. Keep all listed files at the same level.
GitHub Pages should publish from the repository root.

IMPORTANT
- The admission application is a recreation from photographs and must be checked/approved by the school before official use.
- The admissions enquiry form opens an email draft; it does not automatically submit or store learner applications.
- Do not collect identity numbers, medical records or sensitive learner information without an approved secure process.
- Review the privacy notice and confirm all school details before publication.
- Obtain permission before publishing identifiable staff or learner photographs.


ONLINE ADMISSION FORM
Parents can complete Thambatshira_Admission_Application.html online, then use
“Save / download completed application (PDF)” and “Prepare email to school”.
The email button opens the parent's email app. The parent must attach the saved
PDF and supporting documents manually before sending.

STATIC WEBSITE LIMITATION
GitHub Pages cannot securely receive/store applications or automatically attach
files to email. This version does not transmit or store entered form data. The
school must verify and approve the recreated form and submission process before
official use.
